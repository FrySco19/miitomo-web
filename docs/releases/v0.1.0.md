First public preview of **Miitomo Web**, an unofficial browser reconstruction of Miitomo 2.4.0, and of
**Miitomo Reboot**, the new social features built on top of it.

**Try it:** https://frysco19.github.io/miitomo-web/ (add `?reboot=1` for Reboot).

> This release contains **code only**. It does not include the APK or any Nintendo game file. The game reads them
> from your own copy, imported in the page; they stay in your browser.

## Miitomo Web (Classic)
- Miis from the original AFL resource with the original APK shader; body proportions and gestures from the game.
- The room with its original models, camera, state machine, objects, sounds, music and Italian texts.
- First run, Mii Studio editor, personality results, greetings, wardrobe, shop catalogue (no economy), Miifoto.
- Local friends: visit a friend's room, or have a friend visit yours. Local save with export and import.
- Status, feature by feature: [ORIGINAL-PORT-STATUS.md](https://github.com/FrySco19/miitomo-web/blob/main/docs/ORIGINAL-PORT-STATUS.md)

## Miitomo Reboot (new, not in the original game)
- R1 separation from Classic and feature flags · R2 up to 8 Miis in a room · R2b social life ·
  R3 public room · R4 the "Piazza" hub. Local only: visitors are simulated.

## Fixed since the repository was published
- Reboot: a tap during the last line of a conversation ended it instead of pausing it.
- Reboot: an object activity suspended before the public room forbade objects could resume afterwards.
- vite 5.4.21 and fflate 0.8.3.

## Download
`miitomo-web-v0.1.0-web.zip` is the built web client. Unzip it and serve the folder over HTTP (not `file://`),
or use the Windows launchers from the source code.

## Known limitations
The original voice cannot run in a browser; server-side content (questions, coins, ranks, online friends) no longer
exists; Reboot is local only; only the Italian texts are tested. See the README.
